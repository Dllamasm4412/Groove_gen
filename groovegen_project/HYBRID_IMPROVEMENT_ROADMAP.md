# Hybrid Engine Improvement Roadmap

**Scope:** `groovegen/hybrid_render.py` — the canonical drum engine (MusicGen neural bed + genre-idiomatic symbolic drums, beat-warped onto the bed's madmom-detected grid), locked over `continuous.py` after an A/B test.

**Context this roadmap is written against:** GrooveGen is the generative core of a closed-loop BBCI (PPG/GSR/respiration → PD control → music/haptics) for emotion regulation and motor learning. Primary knob = **event density** (monotonic, PD-safe). Secondary anchor = **backbeat on 2 & 4** (entrainment reference). Architecture = **two-timescale**: slow neural bed (regenerated occasionally) + fast symbolic drums (updated per-bar), per `ARCHITECTURE_TWO_TIMESCALE.md`. **Deadline: TEI 2027 system paper, July 31, 2026.**

Every item below is tagged:
- **Deadline flag:** 🔴 PAPER-CRITICAL (blocks or materially strengthens the July 31 submission) / 🟡 PAPER-NICE (helps the paper but not blocking) / ⚪ POST-DEADLINE (ship after submission).
- **EFFORT:** S (hours), M (1–3 days), L (a week+).

## Track 2 — Drum Musicality vs. Coherence (the delicate balance)

**Framing the tension explicitly, because this is the track most likely to be misapplied:** the user just rejected `continuous.py`'s "coherent" engine's approach in an A/B test *in favor of* the hybrid engine's current behavior. Reading the code, hybrid's `render_aligned_drums()` calls `PatternBuilder(...).build_looped()` (`hybrid_render.py` ~line 538 → `groovegen.py::build_looped`, ~line 983): **it builds ONE bar and tiles it bit-identically for the whole clip.** That bit-identical repetition is very likely *part of* what read as more coherent/stable than `continuous.py`'s per-bar `build_varied_drums()` (which re-synthesizes every bar with jittered syncopation and velocity noise — see `ARCHITECTURE_TWO_TIMESCALE.md` §4's "known determinism limitation" discussion). **The rule for every item below: add variety as sparse, scheduled, high-level musical events layered ON TOP of the same tiled core — never as global per-bar stochastic re-randomization of density/syncopation**, because that re-randomization is the mechanism the user's ear already rejected.
